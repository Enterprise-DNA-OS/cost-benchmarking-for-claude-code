# Cost prediction record checks

Checked 26 October 2026. These checks support the surveyor's review. They do not certify a cost prediction, measure a building, interpret a contract or satisfy every professional obligation.

The [RICS Cost prediction professional standard](https://www.rics.org/profession-standards/rics-standards-and-guidance/sector-standards/construction-standards/rics-cost-prediction-professional-statement-global-1st-edition) describes mandatory requirements for RICS professionals and regulated firms producing cost prediction reports. It was reissued in June 2024 without material changes to its regulatory requirements. The [RICS explanation of the standard](https://ww3.rics.org/uk/en/journals/construction-journal/a-new-standard-for-cost-prediction.html) discusses consistent classification, scope, input maturity, data sources and reliable reporting.

| Check | Implementation | Basis and limit |
|---|---|---|
| source | Nonblank evidence reference per plan | Record provenance supports the standard's data-source principle. Presence does not verify evidence. |
| scope | Nonblank project scope | Supports documenting what was estimated. |
| assumptions | Nonblank assumptions | Supports a clear prediction basis. An operator must assess completeness. |
| exclusions | Nonblank exclusions, or explicit none | House record control supporting clear scope. |
| lines | At least one cost element | House completeness control. It does not establish complete scope. |
| future-base | Base date no later than today | House control for comparable historical observations. |
| index-source | Named index series and positive index value | House control for explicit rebasing. No licensed index data is supplied. Record the exact edition and source in the plan evidence. |
| review | Approved status with a reviewer label different from the author | House peer-review control, not an RICS authentication or certification requirement. |

A missing record blocks approval. Uncertainty and contingency are mandatory explicit percentages on new plans. The uncertainty percentage is an operator-stated range, not a calculated confidence interval. Reports retain scope, exclusions, assumptions, source, base date and reviewer. This does not implement full ICMS classification or certify that user codes comply with ICMS. The professional decides the applicable classification and measurement rules.

The 365-day age limit and due date alerts are local operating policies, not statutory deadlines. Benchmark matching requires equal sector, region, work type, currency and index series, selects the latest approved revision of each other project, and excludes stale plans. Rebased rate = comparable total / its area * target index / comparable index. No automatic currency conversion, location factor or market forecast is invented.

Trusted operators supply identity labels. They are not authenticated signatures. The owner can alter the database; SQL controls are not tamper-proof external assurance. Use one protected database per business. Do not connect suppliers or clients to this base without access controls built for that purpose.
