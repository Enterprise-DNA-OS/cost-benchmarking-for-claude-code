# Why this desk has no front end

A quantity surveyor needs comparable evidence, a defensible cost plan and a review record. The database holds those records and the agent runs the same commands each week. Read-only HTML shows the review queue, benchmark library and tender reconciliation. Printable documents carry your business name and colours from brand.json.

A screen gives mobile data entry, drawing takeoff, live collaboration and drag-and-drop editing that this base does not provide. This is a cost evidence desk for trusted internal operators, not a drawing measurement package or a trades job system. Omni by Enterprise DNA builds the web access, document connections and other workflows your version needs.

The code runs with Claude Code, Codex, OpenCode or Cursor. AGENTS.md points to the same operating instructions and command library. The database is the durable part.
